Fixture: 100 pages, 24 sections per page, cross-page heading links, images, lists, quotes, inline/fenced code, a TOC and a tag collection. Five paired repetitions alternate executable order. Every pair compares all generated bytes (including manifests) and JSON reports for check, clean and no-op.

Timing: Bash EPOCHREALTIME wall time includes native process startup and filesystem I/O. Caches are not flushed; fresh output does not mean cold OS cache. Microsecond units do not establish that precision. This single-host synthetic comparison is not a general speed guarantee or a comparison to another SSG. Raw samples are retained in raw.csv; no memory-usage claim is made.

Reproduce: build both revisions with the verified native release toolchain, keep their executables separately, then run `bash scripts/compare-analysis.sh /path/to/before /path/to/after /path/to/new-report-directory`. Set BEFORE_REVISION and AFTER_REVISION to identify the inputs.
