GitHub Pagesで使う

サイト管理を開く。投稿、固定ページ、メディア、サイト設定をここから開けます。編集には対象リポジトリの書き込み権限があるGitHubアカウントでログインします。

新規作成

  1. サイト管理の「投稿・固定ページを作る」を押します。
  2. GitHub Actionsで「Run workflow」を開きます。種類、タイトル、URL名を入力します。本文、抜粋、既存画像、日付、タグ、カテゴリも入力できます。
  3. 本文の改行は \n、段落の区切りは \n\n と入力します。文字として \n を表示するには \\n と入力します。本文はUTF-8で16,000バイトまでです。長文は作成後の「編集を開く」で入力できます。
  4. 下書きとして続ける場合は draft を選びます。公開候補として確認する場合は本文を入れて ready を選び、実行結果のSummaryからPRを作成します。

このプロジェクトのGitHubリポジトリは公開されています。ブランチやPRの内容も閲覧できます。機密の下書きは公開リポジトリに保存しないでください。

編集、画像、公開

  • 公開済みのページは、サイト管理の一覧にある「編集」から開きます。GitHubで新しい作業ブランチに保存し、PRを作成します。
  • 画像は「メディア」の「画像・ファイルを追加」からGitHubにアップロードし、投稿でファイル名を指定します。公開用フォルダに入れた画像は公開対象です。
  • PRの Review Pages changes のSummaryで、追加・更新・削除される公開ファイルと、変更した記事のプレビューを確認します。公開対象外の原稿には下書き・予約などの表示が付きます。記事はGitHubの表示形式で、既存の公開画像を表示します。
  • PRをマージしたら、サイト管理の「Pages公開の結果」を開きます。ビルドが成功したら公開ページを確認します。

クイック編集・一括変更

  1. 管理画面の一覧で原稿名（例 guide.md）をコピーし、「クイック編集」を開きます。
  2. 「Run workflow」で edit を選び、原稿名と変更する項目を入力します。空欄は現状のままです。抜粋を消すなら消去欄に excerpt と入力します。
  3. 実行後のSummaryからPRを作成します。公開差分を確認してマージします。

原稿名をカンマで区切ると、分類や公開状態などを最大20件に適用できます。タイトルとURL名は1件ずつ変更します。公開一覧に載らない原稿の名前は「すべての原稿を開く」で確認できます。URL名を変えたときは、公開差分で古いURLへの影響を確認してください。

  • **複製**は duplicate を選び、原稿名、新しいタイトル、複製先のURL名を指定します。コピーは下書きになります。
  • **復元**は一覧の「履歴」から戻したいコミットの40桁のSHAをコピーし、restore で原稿名とSHAを指定します。
  • **公開予約**はUTCで入力します。設定時刻以降に再公開が必要です。一覧非掲載のページはURLから閲覧できます。

自分のリポジトリで使う

このリポジトリの構成を引き継ぎ、site/site.json の base_url と pages_admin.repository を自分のサイトに合わせます。GitHub Pagesを gh-pages ブランチのルートから公開する設定にして、最初の Publish Pages を実行します。編集対象は main の site/ です。
