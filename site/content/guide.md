# インストールと使い方

## MoonPress Web

ホストで MoonPress Web を用意すると、ブラウザだけで投稿・プレビュー・公開まで進められます。管理 URL でログインし、投稿を作って「公開の確認へ」を押します。確認した変更は同じサービスの `/site/` に反映されます。

[MoonPress Web のホスト設定](https://github.com/furukawa1020/MoonPress/blob/main/docs/web-admin.md)

## Linux版を入手する

[GitHubの配布一覧](https://github.com/furukawa1020/MoonPress/releases)を開き、公開済みのプレビュー版から `moonpress-linux-x86_64.tar.gz` と `SHA256SUMS` を同じフォルダに保存します。Ubuntu 22.04と24.04で検証しています。配布版はMoonBitのインストールなしで起動できます。

ダウンロード先のフォルダで実行します。照合結果が `OK` になってから展開してください。

```sh
sha256sum --check --strict SHA256SUMS
tar -xzf moonpress-linux-x86_64.tar.gz
cd moonpress-linux-x86_64
```

[ソースからビルドする手順](https://github.com/furukawa1020/MoonPress#quick-start)

## サイトを作り、管理画面を開く

展開したフォルダで次の二行を実行します。最初のコマンドは `my-site` にサンプル記事と設定を作ります。既存サイトを開くときは、そのフォルダを二行目に指定してください。

```sh
./moonpress init my-site
./moonpress admin my-site 8080
```

ターミナルを開いたまま、ブラウザで [管理画面を開く](http://127.0.0.1:8080/)。終了するときはターミナルで Ctrl+C を押します。

この公開ガイドは手順を読むためのページです。実際の編集は、起動したPCの管理画面で行います。

## 最初の記事を作ってZIPを取得する

1. [記事を書く](room-write.html)。管理画面で「新しい下書き」を作り、本文を入力して保存します。
2. [プレビューする](room-preview.html)。「プレビューをつくる」を押し、生成したプレビューを開きます。公開したい記事の編集画面で「公開対象にする」を押します。
3. [公開用ファイルを生成する](room-build.html)。変更計画を確認し、確認した内容で公開用ファイルを生成します。
4. [ZIPを取得する](room-publish.html)。「公開用ZIPをダウンロード」を押し、展開したファイルを公開先にアップロードします。

## コメントを確認・編集する

起動した管理画面の「コメント」を開くと、記事ID・投稿者ID・検索語で絞り込めます。コメントのIDを開き、本文・公開表示名・承認状態を確認して保存します。競合が表示された場合は、残された入力を保管して現在のコメントを開き直してください。

承認済みコメントを記事に表示するには「サイト設定」でコメント表示を有効にし、「公開用ビルド」で変更を確認して生成したファイルを公開先へ配置します。

## うまく進まないとき

- 管理画面が開かない場合は、ターミナルで起動に成功したか確認します。8080と8081が使用中なら、両方空いている連続したポートを選びます。たとえば `./moonpress admin my-site 8090` と実行したら、ブラウザでも8090を開きます。
- プレビューに変更が出ない場合は、記事の編集画面で保存してから、プレビューを作り直します。
- ZIPボタンが表示されない場合は、公開用の変更計画を確認して生成し直します。生成後に記事や設定を変更した場合も、同じ手順で作り直してください。

## MoonBitが担当すること

HTMLフォームを受け取り、保存済み記事の検証・依存関係の解析・SHA-256による差分計画・確認済み計画のビルドをネイティブで実行します。ブラウザのJavaScriptやTypeScriptは使いません。

記事はMarkdown、見た目はHTMLとCSS、画像はファイルとして手元に残ります。生成物もHTML・CSS・画像なので、配信先にMoonBitを入れる必要はありません。

配布版では、実Chromeで記事作成からZIP出力までを検証しています。

[入口へ戻る](index.html)

## 記事を探して編集する

管理画面の「記事」で「絞り込み・並び順」を開きます。タイトル・ファイル名・タグの検索、タグの完全一致、日付範囲、日付の有無、掲載状態を組み合わせて探せます。並び順と表示件数を選び、前後ページへ移動しても検索条件を保ちます。日付順では日付のない記事を末尾に表示します。ここでの日付は記事の日付で、更新日時ではありません。

一覧のタイトルから編集し、保存してからプレビューを確認します。「履歴」は保存済みの記事の復元、「参照関係」はURL変更前の確認に使います。編集や一覧の表示だけではデプロイしません。公開対象を確認し、公開用ビルド・ZIP取得を行って公開先へ配置します。

## 投稿を一画面で編集する

管理画面の「投稿」からタイトルを開くと、本文・抜粋・日付・タグ・カテゴリ・URL・掲載・テンプレート・種別・予約を同じ画面で編集できます。「変更を保存」は本文と設定を一緒に保存します。「下書き保存」は編集内容を保存して下書きへ戻します。競合時は入力と元の版を残します。文章を保管し、現在の記事を開いて比較してください。

「文章を追加」で見出し・段落・リスト・引用・コードを、「画像を挿入」でライブラリの画像を本文へ追加できます。追加だけでは保存しません。画像のアップロードは別タブで開き、戻って「画像一覧を更新」すると未保存の文章を保ったまま選べます。

「未保存の本文を確認」は本文だけの確認、「保存してプレビュー」は保存済みの画像・テーマを含むプレビュー生成です。生成失敗時も保存済みかどうかを表示します。「公開の確認へ」で編集を保存して公開対象にし、変更計画・公開用ビルド・ZIP取得へ進みます。ZIPを配置するまでデプロイにはなりません。予約時刻に自動配信する機能はなく、時刻に合わせた再ビルドと配信が必要です。

| WordPressでの操作 | MoonPressでの操作 |
| --- | --- |
| 投稿のタイトルを開く | 「投稿」一覧のタイトルを開く |
| 記事設定を変更して保存 | 本文と右側の設定を編集し「変更を保存」 |
| 下書きを保存 | 「下書き保存」で本文と設定を同時に保存 |
| コンテンツを追加 | 「文章を追加」で見出し・段落・リスト・引用・コードを追加し保存 |
| メディアを追加 | 「画像を挿入」から選択。新規アップロード後は「画像一覧を更新」 |
| プレビュー | 未保存本文の確認、または保存してテーマ付きプレビューを生成 |
| 公開 | 「公開の確認へ」→変更計画→公開用ビルド→ZIPを公開先へ配置 |
