MoonPress はじめの案内 — Linux x86_64 プレビュー版

解凍したフォルダーでターミナルを開きます。MoonBitの導入は不要です。
  ./moonpress init my-site
  ./moonpress admin my-site 8080

http://127.0.0.1:8080/ を開きます。ターミナルは開いたままにします。
8080・8081の両方のポートが必要です。終了はCtrl-Cです。
画面の言語はブラウザ設定から選びます。上部の日本語・English・Auto / 自動で
手動選択と自動選択を切り替えられます。編集中の内容は先に保存してください。

1. 「新しい下書き」でタイトルとファイル名を入れて作成し、「編集を続ける」を開きます。
   本文と右側の記事設定を編集し、「変更を保存」または「下書き保存」を押します。
2. 「文章を追加」で見出しなどを、「画像を挿入」で画像を本文へ追加できます。
   新規画像は別タブのメディア画面で追加し、元の画面で「画像一覧を更新」します。
3. 「保存してプレビュー」を押し、上部の「生成したプレビューを開く」で確認します。
   「公開の確認へ」を押すと編集を保存し、公開対象にして変更計画へ進めます。
4. 変更計画を確認して公開用ファイルを生成し、「ツール」の「公開の準備」から
   公開用ZIPを取得します。展開したファイルをホストへ配置し、公開URLで確認します。

下書きのある .moonpress-preview は公開しません。
公開用ZIPは下書きと管理用の記録を除外します。
保存・ビルド・ダウンロードだけではインターネットに公開されません。

保存が止まったときは管理画面の「編集データの案内所」へ。
詳しくは同梱の RECOVERY.txt を読んでください。ソースは別途バックアップします。
この版はプレビューです。実機電源断・他OS・全ブラウザは未検証です。
ダウンロードしたSHA256SUMSと、解凍後のEXECUTABLE.sha256を確認してください。
https://github.com/furukawa1020/MoonPress

記事の履歴・ゴミ箱・種類・カテゴリー
- 編集画面の履歴リンクから明示的に有効化すると、以後の保存前の内容を保管します。
  版を確認・比較して復元できます。まだ保存していない入力は履歴に残りません。
- ゴミ箱への移動は確認して実行します。Trashから元の空いているファイル名へ
  復元できます。完全削除は確認した保管データだけを消し、元には戻せません。
- Save typeでPostと固定ページを切り替えられます。固定ページは公開されますが、
  投稿一覧・タグ・カテゴリー・RSSには入りません。
- Save categoriesは1行1カテゴリーです。タグとは別です。他の編集を先に保存します。
  公開対象の投稿に設定するとカテゴリー別一覧を生成します。
- これらの保存だけでは公開用ファイルやホストは更新しません。
  WordPressのユーザー権限・コメント・プラグイン互換などは未実装です。

コメントの管理
上部の「コメント」から、記事ID・投稿者ID・検索語で絞り込みます。
コメントのIDを開くと、本文・公開表示名・承認状態を保存できます。
競合が表示された場合は、画面に残った入力を保管して現在のコメントを確認します。
記事に表示するには「サイト設定」でコメント表示を有効にし、「公開用ビルド」で変更を確認して生成物を公開先へ配置します。

## 記事を探して編集する

管理画面の「記事」で「絞り込み・並び順」を開きます。タイトル・ファイル名・タグの検索、タグの完全一致、日付範囲、日付の有無、掲載状態を組み合わせて探せます。並び順と表示件数を選び、前後ページへ移動しても検索条件を保ちます。日付順では日付のない記事を末尾に表示します。ここでの日付は記事の日付で、更新日時ではありません。

一覧のタイトルから編集し、保存してからプレビューを確認します。「履歴」は保存済みの記事の復元、「参照関係」はURL変更前の確認に使います。編集や一覧の表示だけではデプロイしません。公開対象を確認し、公開用ビルド・ZIP取得を行って公開先へ配置します。

## 投稿を一画面で編集する

管理画面の「投稿」からタイトルを開くと、本文・抜粋・日付・タグ・カテゴリ・URL・掲載・テンプレート・種別・予約を同じ画面で編集できます。「変更を保存」は本文と設定を一緒に保存します。「下書き保存」は編集内容を保存して下書きへ戻します。競合時は入力と元の版を残します。文章を保管し、現在の記事を開いて比較してください。

「文章を追加」で見出し・段落・リスト・引用・コードを、「画像を挿入」でライブラリの画像を本文へ追加できます。追加だけでは保存しません。画像のアップロードは別タブで開き、戻って「画像一覧を更新」すると未保存の文章を保ったまま選べます。

「未保存の本文を確認」は本文だけの確認、「保存してプレビュー」は保存済みの画像・テーマを含むプレビュー生成です。生成失敗時も保存済みかどうかを表示します。「公開の確認へ」で編集を保存して公開対象にし、変更計画・公開用ビルド・ZIP取得へ進みます。ZIPを配置するまでデプロイにはなりません。予約時刻に自動配信する機能はなく、時刻に合わせた再ビルドと配信が必要です。
