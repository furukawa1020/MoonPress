MoonPress はじめの案内 — Linux x86_64 プレビュー版

解凍したフォルダーでターミナルを開きます。MoonBitの導入は不要です。
  ./moonpress init my-site
  ./moonpress admin my-site 8080

http://127.0.0.1:8080/rooms を開きます。ターミナルは開いたままにします。
8080・8081の両方のポートが必要です。終了はCtrl-Cです。
画面の言語はブラウザ設定から選びます。上部の日本語・English・Auto / 自動で
手動選択と自動選択を切り替えられます。編集中の内容は先に保存してください。

1. かきかきる〜む：記事をつくり、本文を保存します。画像はMediaから。
2. ぷれびゅ〜る〜む：「プレビューをつくる」を押し、上の
   Open built previewで見た目を確認。記事を編集したら再生成します。
3. 公開したい記事だけ、編集画面で保存してSet ready for buildを押します。
4. こんぱいら〜る〜む：「変更計画をみる」で差分を確認し、
   結果画面のBuild production filesで公開用のファイルを生成します。
5. おひろめる〜む：「公開用ZIPをダウンロード」。展開した中身を
   ホストへ配置し、公開URLで記事・画像・CSSを確認します。

下書きのある .moonpress-preview は公開しません。
公開用ZIPは下書きと管理用の記録を除外します。
保存・ビルド・ダウンロードだけではインターネットに公開されません。

保存が止まったときは管理画面の「編集データの案内所」へ。
詳しくは同梱の RECOVERY.txt を読んでください。ソースは別途バックアップします。
この版はプレビューです。実機電源断・他OS・全ブラウザは未検証です。
ダウンロードしたSHA256SUMSと、解凍後のEXECUTABLE.sha256を確認してください。
https://github.com/furukawa1020/MoonPress

記事の履歴・ゴミ箱・種類・カテゴリー
- 編集画面の履歴リンクから明示的に有効化すると、以後の保存前の内容を保管します。
  版を確認・比較して復元できます。まだ保存していない入力は履歴に残りません。
- ゴミ箱への移動は確認して実行します。Trashから元の空いているファイル名へ
  復元できます。完全削除は確認した保管データだけを消し、元には戻せません。
- Save typeでPostと固定ページを切り替えられます。固定ページは公開されますが、
  投稿一覧・タグ・カテゴリー・RSSには入りません。
- Save categoriesは1行1カテゴリーです。タグとは別です。他の編集を先に保存します。
  公開対象の投稿に設定するとカテゴリー別一覧を生成します。
- これらの保存だけでは公開用ファイルやホストは更新しません。
  WordPressのユーザー権限・コメント・プラグイン互換などは未実装です。
