# ブラウザで MoonPress を使う

MoonPress Web をホストに置くと、利用者は HTTPS の管理 URL を開いて投稿、画像の追加、プレビュー、公開まで行えます。ブラウザには MoonBit やローカルアプリのインストールが不要です。

## サービスを作る

[Render で MoonPress の Blueprint を開く](https://render.com/deploy?repo=https://github.com/furukawa1020/MoonPress)。Render アカウントでリポジトリを接続し、管理者用の長いランダムなパスワードを設定します。Blueprint は有料の Web サービスと 1 GB の永続ディスクを作るため、作成前に Render の料金を確認してください。作成後に Render のサービス URL を開きます。

別の Linux x86_64 コンテナホストでは、このリポジトリの `Dockerfile` を使います。永続ボリュームを `/data` に接続し、`MOONPRESS_ADMIN_PASSWORD` を24〜256バイトのランダムな値としてシークレットに設定してください。公開オリジンは Render と Railway の標準ドメインから取得します。独自ドメインでは `MOONPRESS_WEB_ORIGIN` を末尾スラッシュなしの正規 HTTPS オリジンに設定します。TLS はホストの入口で終端し、外部には `PORT` だけを公開します。ヘルスチェックには `/healthz` を指定します。

データを持つ単一インスタンスとして運用します。入れ替え時は古いインスタンスを停止してから同じディスクで起動します。移行や復元の前に `/data` をバックアップしてください。投稿、設定、画像と生成済みのサイトは `/data/site` に保存されます。

## 投稿して公開する

1. 管理 URL を開き、ユーザー名 `admin` と設定したパスワードで入ります。
2. 「投稿」で新しい下書きを作り、「編集を続ける」を開きます。本文と設定を書き、「下書き保存」を押します。
3. 「保存してプレビュー」を押し、「生成したプレビューを開く」でテーマと画像を確認します。下書きのプレビューにはログインが必要です。
4. 「公開の確認へ」で公開候補を保存し、変更計画を確認します。「確認した変更を公開」を押すと、同じサービスの `/site/` に反映されます。
5. 「公開サイトを開く」で確認します。公開ページはログインなしで読めます。

公開するたびに計画を照合します。確認後に編集した場合は再確認が必要です。公開 URL に配信するのは検証済みの公開用出力だけです。

RSS・サイトマップを有効にする場合は、サイト設定の公開 URL に実際の `https://ホスト名/site/` を設定してください。管理機能は単一の管理者向けです。サイトを別の静的ホストに移す場合は公開用 ZIP を取得できます。
